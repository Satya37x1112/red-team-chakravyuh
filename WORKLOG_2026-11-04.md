## 2. THC-Hydra integration (main kaam)

Hydra ko **bruteforce module ka real credential-test driver** banaya — bilkul waise
jaise Locust DDoS ka real driver hai. Module ka `execute()` simulation hi rehta hai;
real path ek **fail-closed integration adapter** ke peeche hai.

**Nayi / badli files:**

| File | Change |
|------|--------|
| `backend/app/integrations/hydra.py` | **Naya** `HydraIntegration` adapter — detect / status / preconditions / run |
| `backend/app/integrations/__init__.py` | Registry mein `hydra` register |
| `backend/app/config.py` | Hydra settings: bin, enable, target, service, user/pass list, caps |
| `backend/app/api/integrations.py` | `POST /api/integrations/hydra/run` — gated endpoint (423 jab disarmed) |

| `frontend/src/pages/Integrations.tsx` | Dashboard pe Hydra panel + honest result/message display |
| `frontend/src/api.ts` | `hydraRun()` API call |

**Safety posture (project boundary maintain):**
- Fail-closed gate: `HYDRA_ENABLED=true` + authorized target + user-list + pass-list — chaaron zaroori
- Hard caps: attempts (500), parallel tasks (4), duration (120s) — request ghata sakti, badha nahi sakti
- Fixed scope: sirf wahi ek list-pair, wahi ek target+service — arbitrary host/creds request se nahi
- No shell, hard timeout; **cracked password kabhi UI pe return nahi hota** — sirf "login X pe weak creds" dikhta hai
- Binary/config missing → adapter honestly "unavailable"/"disarmed" batata hai, crash nahi

## 4. Live SMB test (is device pe, authorized self-test)

- Target: is Windows host ki SMB (`172.26.240.1:445`) — WSL→host firewall ke liye ek
  temporary scoped rule add karni padi (`TEMP-WSL-SMB-hydra`, WSL subnet `/20`)
- **Result (honest):** pipeline poori sahi chali — detect → armed → reachable → run →
  parse → artifact save → error surface. Par **hydra 9.5 ka SMB module modern Win11 SMB
  (SMBv3 + signing) se baat nahi kar paata** → `[ERROR] invalid reply from target`,
  0 valid pairs. Koi fake result nahi diya.
- Ye ek real-world finding hai: SMB brute-force Win11 pe flaky; clean success demo ke liye
  SSH-based throwaway target behtar rehta hai.

> **Cleanup reminder:** test khatam hone par firewall rule hata dena —
> `Remove-NetFirewallRule -DisplayName "TEMP-WSL-SMB-hydra"`
